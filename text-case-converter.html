When to use each case

UPPERCASE: Headers, emphasis, acronyms. Use sparingly — it's harder to read in long blocks.

Title Case: Titles, headlines, video titles. Capitalizes major words — perfect for YouTube titles.

snake_case: File names, database columns, Python variables.

camelCase: JavaScript variables, function names, JSON keys.

kebab-case: URLs, CSS classes, HTML IDs, file names for the web.

Converter FAQ

Is my text uploaded?

Can I convert large texts?

Yes — there's no practical limit other than your browser's textarea capacity.
